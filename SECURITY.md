# Security

## Reporting a vulnerability

Please do not open a public issue. Email **security@example.com** (placeholder, to be replaced) with
what you found, how to reproduce it, and the Native version and channel. Once the repository is on
GitHub, private vulnerability reporting under the Security tab also works.

We aim to acknowledge reports within a few days and will credit you if you want.

## Scope

Native runs agents with your permissions, hosts a sandboxed script runtime, and manages sessions in a
durable host. Reports about sandbox escapes, approval bypasses, host protocol authentication and
update integrity are especially welcome.
