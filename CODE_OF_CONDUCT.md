# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone in issues, pull requests, discussions and any other project space, and to
agents acting on someone's behalf.

handled privately.
